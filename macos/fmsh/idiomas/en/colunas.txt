#  COMO PREENCHER
#
#   1. Nao mude nada ANTES do sinal de igual. Aquilo e o nome
#      interno da frase; o app procura por ele.
#
#   2. O que estiver entre {{chaves duplas}} o app troca por um
#      valor na hora (um nome, um numero). Copie igual, sem
#      traduzir o que esta dentro.
#
#   3. Linha que comeca com # e comentario: serve so para voce
#      ler, e o app ignora.
#
#   4. Esqueceu uma linha? Nao quebra nada. Aquela frase aparece
#      em ingles e o resto continua no seu idioma.
#
#   5. Para escrever uma quebra de linha dentro de um texto, use
#      as duas letras \n.
#
#  Depois de salvar, feche e abra o FMSH para ver o resultado.
#

#  Cada coluna tem um NOME inteiro e uma SIGLA curta. A sigla aparece
#  no cabecalho da tabela, entao precisa ser curta de verdade.
#
#  A chave e sempre a mesma para todos os idiomas -- ela sai do nome
#  em portugues e nao quer dizer nada; ignore. O que interessa e o
#  texto original, que vai no comentario acima de cada uma.
