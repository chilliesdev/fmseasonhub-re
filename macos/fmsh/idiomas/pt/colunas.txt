#      ler, e o app ignora.
#
#   4. Esqueceu uma linha? Nao quebra nada. Aquela frase aparece
#      em ingles e o resto continua no seu idioma.
#
#   5. Para escrever uma quebra de linha dentro de um texto, use
#      as duas letras \n.
#
#  Depois de salvar, feche e abra o FMSH para ver o resultado.

#  no cabecalho da tabela, entao precisa ser curta de verdade.

#  em portugues e nao quer dizer nada; ignore. O que interessa e o
#  texto original, que vai no comentario acima de cada uma.
