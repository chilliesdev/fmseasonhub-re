FM Season Hub - macOS installation

Requires macOS 15 or later. Python and app dependencies are included.

1. Quit any older copy of FM Season Hub.
2. Drag FM Season Hub.app to the Applications shortcut in this window.
3. Eject the FM Season Hub disk image.
4. Open FM Season Hub from Applications.

Keep your existing Documents/FM Season Hub folder. It contains your app data.

Connect Football Manager

If Hub reports denied game access, save and close Football Manager.
Select Launch FM with Hub in the error dialog. Load your save, then select
Try again. This starts FM26 from your Steam library with the Hub memory bridge.
Hub never closes your game. Keep Steam open and signed in.

First launch

This build is ad-hoc signed. It has no Apple Developer ID signature or
notarization. A DMG does not remove Apple's security warning.

If macOS says Apple could not verify the app from the official project release:

1. Click Done in the warning.
2. Open System Settings and select Privacy & Security in the sidebar.
3. Scroll down in the right pane to the Security section.
4. Click Open Anyway beside the message that FM Season Hub was blocked.
5. Confirm Open and enter your Mac login password or use Touch ID if asked.

This approves only this app.
